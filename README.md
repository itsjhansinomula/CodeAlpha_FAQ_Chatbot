# 🤖 CodeAlpha - FAQ Chatbot

## 📌 Project Overview
An AI-powered FAQ Chatbot that answers questions about CodeAlpha Internship using NLP - TF-IDF + Cosine Similarity.
Built as Task 2 of CodeAlpha Artificial Intelligence Internship.

## ✨ Features
- Answers questions instantly about Internship, Certificate, Tasks
- Uses TF-IDF Vectorizer + Cosine Similarity for matching
- Chat history maintained
- Suggested questions for users
- Simple Streamlit UI

## 🛠️ Technologies Used
- Python
- Streamlit
- Scikit-learn (TF-IDF, Cosine Similarity)

## 🚀 How to Run
1. Clone this repo
2. Install requirements: `pip install -r requirements.txt`
3. Run app: `streamlit run app.py`
